# Package icon
Replace `icon.png` in this folder with your own image, preferably a square PNG.
The included image was generated with Microsoft Copilot for this unofficial integration.
It is not an official Prusa or Synology application icon.
The SPK build automatically generates all required sizes. No NAS shell access is needed.
Manual preview: `python tools/generate_icons.py` (requires requirements-build.txt).
